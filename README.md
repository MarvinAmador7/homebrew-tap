# MarvinAmador7/homebrew-tap

Homebrew formulae for [capcomd](https://github.com/MarvinAmador7/capcomd).

```
brew install MarvinAmador7/tap/capcomd
```

`brew upgrade capcomd` moves to the latest release.

`Formula/capcomd.rb` is written by capcomd's release workflow for each release (from `scripts/homebrew-formula.ts`
in that repository); don't edit it here, since the next release overwrites it.
